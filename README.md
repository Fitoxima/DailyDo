# DailyDo 📝

A sleek, modern, local-first To-Do Android application built with Jetpack Compose.

## Features
- 🔔 **Smart Reminders:** Interactive notifications (Mark Done / Postpone) with custom repeating alarms.
- ⚡ **Dynamic UI:** Custom splash screen, neon glow animations for tasks that are "Due Now", and custom themes.
- 🔒 **Privacy First:** 100% offline. All data is stored locally using Room Database and DataStore.
- 🎨 **Custom Design:** Unique Category pills, priority trackers, and Material 3 dark/light mode.

## Tech Stack
- **UI:** Jetpack Compose, Material 3
- **Architecture:** MVVM, Kotlin Coroutines, StateFlow
- **Database:** Room (Local)
- **Settings:** DataStore Preferences
- **Background Tasks:** AlarmManager, BroadcastReceivers
- **Security:** Proguard/R8, secure release signing.
